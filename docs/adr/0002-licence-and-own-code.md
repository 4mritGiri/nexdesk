# 2. Licence and own-code rule
Status: accepted

**Decision.** `MIT OR Apache-2.0`. All code is written for this project or comes from permissively licensed dependencies. Source is never copied from other remote-desktop or terminal projects, whatever their licence.
**Consequences.** Wide adoption and no copyleft obligations for users; contributors sign off the Developer Certificate of Origin; reading other projects for ideas is allowed, copying is not.
